# AI usage

This project is deliberately built to use AI agents as much as possible. **All code and documentation in this repository is written by AI agents unless it is marked as written by hand.**

AI is involved at two levels:

- **Building the project.** AI coding agents write the extension, the monitoring pipeline, the tests and the docs, including this file and the README.
- **Running the project.** A vision model reviews screenshots, and a repair agent proposes selector fixes when YouTube's layout changes.

The human maintainer sets direction, reviews changes and decides what gets merged. No agent-written change reaches the extension without human approval.
